# 自定义扩展草稿（当前不启用）

这里保留早期的直连、代理、局域网、排除规则，以及当时的路由预期记录。它们均不被当前基础构建读取，也不出现在已发布的基础订阅中。修改这些文件不会改变基础规则。

`legacy-route-expectations.json` 仅记录旧版预期，不能作为当前原版基础已覆盖这些服务的证明。`exclude.list` 内旧注释描述的是以前的构建行为，当前不生效。

未来扩展应生成独立订阅，再在客户端显式启用并设置优先级。需要改变某个域名的去向时，在扩展中添加覆盖；保持 `upstream/blackmatrix7/` 和 `dist/base/` 的原版文件不变。每次新增扩展须说明来源、意图、验证结果和启用方式。

当前基础不承诺额外覆盖 Typeless、Grok、所有飞书/银行域名；应以基础实际文件和客户端连接记录为准。
